Standing Pigs (Minecraft Forge 1.20.1)
======================================
หมูยืนสองขา เดินแกว่งแขน

วิธีได้ไฟล์ .jar:
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ .github) ขึ้น GitHub repository
2. เปิดแท็บ Actions รอจนขึ้นเครื่องหมายถูกสีเขียว
3. คลิกรอบ build -> Artifacts -> standing-pigs-jar -> แตก zip จะได้ .jar
4. วางไฟล์ .jar ในโฟลเดอร์ mods ของ Minecraft 1.20.1 ที่ลง Forge 47.x

ถ้า build ไม่ผ่าน ให้ก๊อปข้อความ error สีแดงมาให้ Claude
